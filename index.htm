  • Press the Start any button to begin the game.
  • Watch carefully as the game highlights a color.
  • Click the same color that the game shows.
  • In each new level, remember the previous sequence and add the new color.
  • Repeat the complete sequence in the correct order.
  • If you click the wrong color, the game is over.
  • Try to reach the highest level possible!
